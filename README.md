
# Birthday Paradox Simulation

A Python project exploring the Birthday Paradox through random birthday generation and duplicate detection.

## About the Project

The Birthday Paradox demonstrates that in a group of just 23 people, there is approximately a 50% probability that at least two people share the same birthday.

This project uses Python to generate random birthdays and check for matching dates.

## Features

- Random birthday generation
- Generate birthdays for 23 people
- Detect matching birthdays
- Display matching dates

## Python Concepts Used

- Variables and Data Types
- Functions
- Lists
- Loops
- Conditional Statements
- Random Module
- Datetime Module
- Sets

## Current Progress

The project currently generates 23 random birthdays and detects matching dates.

Monte Carlo simulation is planned as the next development stage.
